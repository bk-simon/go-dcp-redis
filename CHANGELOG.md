## [0.0.2] - 2025-02-18

### Added

- **Redis Cluster support**: Connect to Redis Cluster for horizontal scaling and high availability. Configuration supports cluster node addresses, optional username/password, and options for `routeByLatency`, `routeRandomly`, and `readOnly`. See [Redis Cluster Configuration](README.md#redis-cluster-configuration) in the README for usage.
